# mineONrust

Быстрый voxel-прототип на Rust + Bevy для Linux.

## Запуск

Нужен Rust toolchain с поддержкой `cargo` и системные библиотеки окна Linux:

```bash
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
source "$HOME/.cargo/env"
cargo run --release
```

Управление: `WASD` — полёт, `Space`/`Shift` — вверх/вниз, мышь — обзор, ЛКМ — убрать блок, ПКМ — поставить блок.

Рендер строит одну GPU-сетку только из открытых граней, хранит блоки в плоском массиве и собирается с thin LTO. Следующий шаг для больших миров — вынести сетку в независимые чанки и перестраивать только изменённый чанк.
