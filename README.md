# mineONrust

Voxel-прототип на Rust + Bevy для Linux с большим процедурным миром.

## Запуск

Нужен Rust toolchain с поддержкой `cargo` и системные библиотеки окна Linux:

```bash
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
source "$HOME/.cargo/env"
cargo run --release
```

На CachyOS перед первой сборкой:

```bash
sudo pacman -S --needed base-devel pkgconf libx11 libxcursor libxrandr libxi libxinerama libxkbcommon
rustup default stable
```

Управление: `WASD` — ходьба, двойной `Space` — включить/выключить полёт, одиночный `Space` — прыжок, `Shift` — вниз в полёте, мышь — обзор, ЛКМ — убрать блок, ПКМ — поставить блок.

## Что внутри

- мир размером `512 x 512` блоков по горизонтали и `96` по высоте;
- детерминированная псевдослучайная генерация холмов и долин;
- плоское компактное хранение блоков и отрисовка только открытых граней;
- отдельные GPU-материалы для верхней, боковой и нижней граней;
- пользовательские текстуры в `assets/grass_top.jpg`, `assets/grass_side.png` и `assets/dirt_bottom.png`;
- голубое небо, освещение, прицел и рука от первого лица;
- release-профиль с thin LTO и одним codegen unit.
- коллизии блоков, гравитация и прыжок;
- vsync, отключённые динамические тени и дальность рендера `160` блоков для меньшего нагрева GPU.

Для действительно бесконечного мира следующим этапом будут независимые чанки с фоновой генерацией и перестройкой только изменённого чанка.
